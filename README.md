# JD INFYNIX SOLUTIONS — Vercel

React + Vite professional company website.

## Run
npm install
npm run dev

## Build
npm run build

## Vercel
Import this project/repository into Vercel. Framework: Vite. Build: npm run build. Output: dist.

## Domain
Add jdinfynixsolutions.in under Vercel Project Settings > Domains and follow the DNS records Vercel provides.

The enquiry form opens WhatsApp, so no paid backend is required.
